# 💣 펑펑 아레나

링크 하나로 팀원들이 모여서 하는 3D 폭탄 아레나 멀티게임입니다. 보통 4명, 최대 6명이 함께 플레이해요.
three.js로 그리고, Node.js 서버가 게임 판정을 맡습니다.

## 플레이 방법

1. 사이트에 접속하면 주소 끝에 방 코드가 붙습니다 (예: `https://…/#k3vq7p`).
2. 닉네임을 쓰고, 3D 미리보기로 캐릭터 외형을 보면서 고른 뒤 **입장하기**를 누릅니다. 이미 누가 쓰는 캐릭터면 다른 캐릭터로 바뀌고, 대기실에서 다시 고를 수 있어요.
3. **🔗 초대 링크 복사**를 눌러 팀원에게 보냅니다. 같은 링크로 들어온 사람은 같은 방에 모입니다.
4. 방장(👑)이 맵 카드(빙하·화산·숲속·사막·🎲 랜덤) 중 하나를 고르고 **게임 시작**을 누릅니다.

| 조작 | 키 |
|---|---|
| 이동 | 방향키 또는 WASD |
| 폭탄 | Space |

- 마지막까지 살아남은 사람이 승리합니다. 승수는 방에 누적돼요.
- 🤖 **AI 봇**: 방장이 대기실에서 봇 수를 정할 수 있어요 (사람 + 봇 최대 6명). 혼자서도 연습할 수 있어요.
- **개인전 / 팀전**: 사람 + 봇이 4명 또는 6명이면 팀전을 고를 수 있어요. 팀전에서는 맞아도 바로 죽지 않고 🫧 물방울에 5초 갇히고, 같은 팀이 닿으면 구출, 상대가 닿거나 시간이 다 되면 탈락해요.
- 블록을 부수면 아이템이 나옵니다: 💣 폭탄 개수 +1, 🔥 화력 +1, 👟 속도 +1
- ⚽ **축구화**: 폭탄 쪽으로 걸어가면 폭탄을 찹니다. 막힐 때까지 미끄러져요.
- 🧤 **글러브**: 폭탄을 놓고 그 위에서 Space를 한 번 더 누르면 3칸 앞으로 던집니다. 벽도 넘어가요.
- 개발 중 아이템을 바로 시험하려면 `DEV_ITEMS=1 npm start`로 실행하세요 (시작부터 축구화·글러브 보유, 스폰 옆에 아이템 5종). `DEV_CLEAR=1`을 붙이면 부서지는 블록 없이 시작해서 맵 기믹을 바로 확인할 수 있어요.
- 맵 5종마다 기믹이 있어요: 🧊 얼음 미끄러짐·언 상자, 🌋 용암 균열 분출, 🍄 버섯 점프·덤불 숨기, 🌀 워프·유사 감속·모래폭풍, 🎢 놀이공원 컨베이어 벨트(폭탄도 실려 감)·트램펄린
- 한 판은 5분이에요. 마지막 60초는 ⚠️ **서든데스**: 바깥부터 벽이 떨어지니 가운데로 모이세요!
- 🏆 **세트제**: 방장이 1판 / 3판 2선승 / 5판 3선승을 고를 수 있어요. 판이 끝나면 자동으로 다음 판이 시작돼요.
- 개발 중 서든데스를 바로 확인하려면 `DEV_SUDDEN=1 npm start` (서든데스 3초 전부터 시작).
- 왼쪽 아래 🔊 🎵 버튼으로 효과음과 배경음을 켜고 끌 수 있어요.
- 7번째부터 들어온 사람은 관전합니다. 게임 중에 들어온 사람은 다음 판부터 참가해요.

## 로컬에서 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 창을 여러 개 띄우면 혼자서도 멀티 테스트를 할 수 있어요.

같은 와이파이에 있는 팀원과 바로 하려면 빌드해서 실행한 뒤 `http://내-PC-IP:3000`을 공유하세요.

```bash
npm run build && npm start
```

## 배포 (팀원과 인터넷으로 공유)

### Render (무료, 추천)

1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. [render.com](https://render.com)에 GitHub로 로그인합니다.
3. **New → Blueprint**를 누르고 저장소를 고르면 `render.yaml` 설정대로 배포됩니다.
4. 발급된 `https://popop-arena-xxxx.onrender.com` 주소를 팀원에게 공유하면 끝입니다.

> 무료 플랜은 15분 동안 접속이 없으면 서버가 잠듭니다. 첫 접속 때 30~60초쯤 기다리면 깨어나요.
> 항상 켜 두려면 유료 플랜(월 $7)으로 바꾸면 됩니다.

### 그 외

`Dockerfile`이 있어서 Fly.io, Railway, 개인 서버 등 컨테이너를 지원하는 곳이면 어디든 배포할 수 있습니다.
서버는 `PORT` 환경 변수의 포트 하나로 웹페이지와 WebSocket(`/ws`)을 함께 제공합니다.

## 개발 명령

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 (코드 수정 시 자동 반영) |
| `npm test` | 게임 규칙 단위 테스트 |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 클라이언트 빌드 (`dist/`) |
| `npm start` | 운영 서버 실행 |

설계 내용은 [DESIGN.md](DESIGN.md)에 정리되어 있습니다.
